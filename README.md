# RAG MasterClass

A practical Retrieval-Augmented Generation (RAG) project that shows how to build a question-answering system over your own text data using LangChain, Hugging Face embeddings, Chroma, and a Groq-hosted LLM.

This project is implemented as a Jupyter notebook and demonstrates the core pipeline for grounding model responses in external knowledge:

- load a custom text document
- split it into manageable chunks
- generate embeddings for each chunk
- store the embeddings in a vector database
- retrieve the most relevant chunks for a query
- pass the retrieved context to an LLM for an informed answer

## Project Overview

The notebook in this repository walks through a complete RAG workflow using your own content rather than a prebuilt knowledge source. It is useful for learning how RAG works in practice and for building a foundation for more advanced document-based AI applications.

## Prerequisites

Before running the project, make sure you have:

- Python 3.12 or later
- A Groq API key
- A local environment manager such as `uv` or `venv`
- Jupyter Notebook installed

## Setup

### 1. Clone the repository

```bash
git clone <your-repo-url>
cd RAG_MasterClass
```

### 2. Create a virtual environment

Using `uv`:

```bash
uv sync
```

Or using `venv`:

```bash
python -m venv .venv
source .venv/bin/activate    # macOS/Linux
.venv\Scripts\activate       # Windows
pip install -e .
```

### 3. Create a `.env` file

Create a file named `.env` in the project root with the following values:

```env
GROQ_API_KEY=your_groq_api_key_here
GROQ_MODEL=llama3-8b-8192
```

> The model name is optional because the notebook defaults to `llama3-8b-8192` if it is not provided.

## Running the Notebook

Start Jupyter from the project root:

```bash
jupyter notebook
```

Then open:

```text
1.0_RAG_With_Own_Text.ipynb
```

The notebook covers the full workflow:

1. Prepare a custom document
2. Split it into chunks
3. Generate embeddings using `all-MiniLM-L6-v2`
4. Store embeddings in Chroma
5. Run semantic similarity search
6. Pass the retrieved context to the Groq LLM for answer generation

## Example Workflow

The project uses code similar to the following pattern:

```python
from langchain_core.documents import Document
from langchain_text_splitters import RecursiveCharacterTextSplitter
from langchain_huggingface import HuggingFaceEmbeddings
from langchain_community.vectorstores import Chroma
from langchain_groq import ChatGroq

llm = ChatGroq(
    model="llama3-8b-8192",
    temperature=0.0,
    groq_api_key=os.getenv("GROQ_API_KEY")
)
```

The notebook then:

- creates a document from custom text
- chunks it with `RecursiveCharacterTextSplitter`
- embeds the chunks with Hugging Face
- loads them into Chroma
- calls `similarity_search()` to retrieve relevant passages
- sends the context to the LLM to ground the final response

## Notes

- This project is designed for learning and experimentation.
- The vector store is created locally and is ideal for small to medium document-based demos.
- For production systems, you would typically add persistence, metadata filtering, prompt engineering, chunk optimization, and evaluation.
